# Security Policy

## Supported versions

Until the first stable release, security fixes are made on the latest published
`0.x` release and on the default branch. Older pre-release versions are not
maintained.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** flow in the repository Security tab so the report,
proof of concept, and discussion remain private.

Include the affected package and version, impact, reproduction steps, and any
suggested mitigation. A maintainer will acknowledge a complete report within
five business days and will coordinate disclosure after a fix is available.

Security reports concerning React, Recharts, D3, or another upstream dependency
should also be reported to that project when the issue is not specific to Chart
Elements.
